🚀 Zoho Books Migration - Visual Guide

📌 Migration Overview
This guide walks you through exporting your GST accounting data and importing it into Zoho Books. Total time: ~1-2 hours depending on data volume.
1 Prepare Your Environment
Ensure all prerequisites are met before starting the export process.
  • ✅ Database is accessible and up-to-date
  • ✅ PHP 7.4+ installed with PDO extension
  • ✅ exports/ directory is writable
  • ✅ Zoho Books account created
# Test database connection
php -r "require 'db.php'; db(); echo 'Connected!\n';"
↓
2 Export Your Data
Run the export utility to generate CSV files compatible with Zoho Books.
# Export all data types
php zoho_export.php all

# Or use the web interface
php -S 0.0.0.0:8080
# Visit: http://localhost:8080/zoho_export.php
Generated files:

📇 Contacts

zoho_contacts_*.csv

Customers & Vendors with GSTIN

📦 Items

zoho_items_*.csv

Products with HSN codes

💰 Sales

zoho_sales_invoices_*.csv

Sales invoices with GST

🛒 Purchases

zoho_purchase_invoices_*.csv

Purchase bills with ITC

↓
3 Configure Zoho Books
Set up your organization and tax rates before importing data.
Open Zoho Books →
  • Log in to Zoho Books
  • Settings → Organization Profile (verify GSTIN, state)
  • Settings → Taxes → Create GST rates:
    • GST @ 5%, 12%, 18%, 28% (CGST+SGST groups)
    • IGST @ 5%, 12%, 18%, 28%
↓
4 Import Contacts (CRITICAL FIRST STEP)
⚠️ IMPORTANT: Contacts MUST be imported before invoices!
  • Go to Settings → Import Data → Contacts
  • Upload zoho_contacts_*.csv
  • Map columns (auto-detected from headers)
  • Review and click Import
  • Check import log for errors
  • Fix any GSTIN validation issues
⚠️ Common Issues:
  • Duplicate GSTIN errors → Consolidate duplicate parties
  • Invalid GSTIN format → Fix in source database and re-export
↓
5 Import Items (Products)
Import your product catalog with HSN codes.
  • Settings → Import Data → Items
  • Upload zoho_items_*.csv
  • Map columns and import
  • After import: Configure tax rates for each item
  • Update sales/purchase rates as needed
↓
6 Import Sales Invoices
Import your sales transaction history.
  • Settings → Import Data → Invoices
  • Upload zoho_sales_invoices_*.csv
  • Zoho will match customer names from Step 4
  • Review import errors (usually name mismatches)
  • Verify tax calculations
↓
7 Import Purchase Invoices
Import your purchase/bills history.
  • Settings → Import Data → Bills
  • Upload zoho_purchase_invoices_*.csv
  • Match vendors from imported contacts
  • Tag bills for ITC eligibility
↓
8 Verify Data Integrity
Perform thorough verification before going live.
  • Check import success rates in Settings → Import History
  • Compare record counts with source database
  • Verify GST calculations: Reports → GST Reports
  • Spot-check random invoices for accuracy
  • Generate trial GSTR-1 and compare with previous returns
✅ Verification Checklist:
  • Total sales match between systems
  • Total purchases match between systems
  • GST liability calculations are correct
  • All parties have been imported
  • All active items are present
↓
9 Post-Migration Setup
Configure Zoho Books for day-to-day operations.
  • Set up invoice numbering sequences
  • Configure invoice templates and terms
  • Add team members and set permissions
  • Connect payment gateways if needed
  • Set up automated payment reminders
  • Configure bank feeds/reconciliation
↓
✓ Go Live!
You're ready to use Zoho Books for your accounting.
🎉 Congratulations! Your data has been successfully migrated to Zoho Books.

Recommended: Run both systems in parallel for 1-2 months to ensure everything works correctly.
