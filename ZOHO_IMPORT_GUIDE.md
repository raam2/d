# Zoho Books Import Guide

## Overview

This guide will help you upload your existing accounting data from the database-driven GST accounting system to Zoho Books (https://books.zoho.in/app).

## Prerequisites

1. Active Zoho Books account (sign up at https://books.zoho.in/app if needed)
2. Access to this repository and database
3. Export files generated by `zoho_export.php`

## Step-by-Step Process

### Step 1: Generate Export Files

You can export your data in two ways:

#### Option A: Web Interface
1. Open your browser and navigate to: `http://your-server/zoho_export.php`
2. Click on each export button:
   - Export Contacts
   - Export Items  
   - Export Sales Invoices
   - Export Purchase Invoices
3. Files will be saved in the `/exports/` directory

#### Option B: Command Line
```bash
# Export everything at once
php zoho_export.php all

# Or export specific types
php zoho_export.php contacts
php zoho_export.php items
php zoho_export.php sales
php zoho_export.php purchases
```

Generated files will be in `/exports/` directory with timestamps:
- `zoho_contacts_YYYY-MM-DD_HHMMSS.csv`
- `zoho_items_YYYY-MM-DD_HHMMSS.csv`
- `zoho_sales_invoices_YYYY-MM-DD_HHMMSS.csv`
- `zoho_purchase_invoices_YYYY-MM-DD_HHMMSS.csv`

### Step 2: Log in to Zoho Books

1. Visit https://books.zoho.in/app
2. Sign in with your Zoho account credentials
3. If prompted, select your organization or create a new one

### Step 3: Configure Organization Settings

Before importing data, ensure your organization is properly configured:

1. Go to **Settings** (gear icon) → **Organization Profile**
2. Verify:
   - Company name
   - Address
   - GSTIN (if registered)
   - State
   - Currency (should be INR)
   - Financial year

### Step 4: Set Up Tax Rates

GST rates need to be configured before importing:

1. Go to **Settings** → **Taxes**
2. Click **+ New Tax** to create common GST rates:
   - **IGST @ 5%** (Type: Tax, Rate: 5%)
   - **IGST @ 12%** (Type: Tax, Rate: 12%)
   - **IGST @ 18%** (Type: Tax, Rate: 18%)
   - **IGST @ 28%** (Type: Tax, Rate: 28%)
   - **GST @ 5%** (Type: Tax Group, CGST 2.5% + SGST 2.5%)
   - **GST @ 12%** (Type: Tax Group, CGST 6% + SGST 6%)
   - **GST @ 18%** (Type: Tax Group, CGST 9% + SGST 9%)
   - **GST @ 28%** (Type: Tax Group, CGST 14% + SGST 14%)

### Step 5: Import Contacts (Critical - Do This First!)

**IMPORTANT**: Contacts must be imported before invoices, as Zoho Books needs to match customer/vendor names.

1. Go to **Settings** → **Import Data**
2. Select **Contacts**
3. Click **Import Contacts from CSV**
4. Upload the `zoho_contacts_*.csv` file
5. Map the CSV columns to Zoho fields (the script already uses correct headers):
   - Contact Name → Contact Name
   - GSTIN → GST Identification Number
   - Contact Type → Contact Type (Customer/Vendor)
   - etc.
6. Review the mapping preview
7. Click **Import** and wait for completion
8. Review any warnings or errors:
   - Duplicate GSTINs will be flagged
   - Invalid GSTIN format will be reported
   - Fix issues and re-import if necessary

**Post-Import Tasks:**
- Review imported contacts: **Contacts** → **All Contacts**
- Update missing information (email, phone, addresses)
- Set payment terms for key customers/vendors
- Set credit limits if applicable

### Step 6: Import Items (Products)

1. Go to **Settings** → **Import Data**
2. Select **Items**
3. Click **Import Items from CSV**
4. Upload the `zoho_items_*.csv` file
5. Map columns:
   - Item Name → Item Name
   - SKU → SKU
   - HSN/SAC → HSN/SAC
   - Unit → Unit
   - etc.
6. Review and click **Import**

**Post-Import Tasks:**
- Go to **Items** to review imported products
- Update missing information:
  - Sales Rate (selling price)
  - Purchase Rate (cost price)
  - Default Tax rate for each item
  - Stock tracking settings
  - Reorder levels
- Assign correct tax rates based on HSN codes
- Update descriptions if needed

### Step 7: Import Sales Invoices

1. Go to **Settings** → **Import Data**
2. Select **Invoices** or **Sales Invoices**
3. Upload the `zoho_sales_invoices_*.csv` file
4. Map columns:
   - Invoice Number → Invoice#
   - Customer Name → Customer Name
   - Invoice Date → Invoice Date
   - Item Name → Item Name
   - etc.
5. Review mapping and click **Import**

**Important Notes:**
- Zoho will try to match Customer Names from the Contacts you imported
- If a customer name doesn't match exactly, the import will fail for that invoice
- The script exports "final" status invoices only
- Tax calculations will be done by Zoho based on your tax configuration

**Post-Import Tasks:**
- Review imported invoices: **Sales** → **Invoices**
- Check for any failed imports and resolve
- Verify tax calculations
- Update payment status if applicable
- Send invoices to customers if needed

### Step 8: Import Purchase Invoices

1. Go to **Settings** → **Import Data**
2. Select **Bills** or **Purchase Invoices**
3. Upload the `zoho_purchase_invoices_*.csv` file
4. Map columns appropriately
5. Review and import

**Post-Import Tasks:**
- Review: **Purchases** → **Bills**
- Verify vendor matching
- Update payment status
- Tag bills for ITC (Input Tax Credit) eligibility

### Step 9: Verify Data Integrity

After all imports, perform these checks:

1. **Contacts Verification:**
   ```
   Settings → Import History → Contacts
   ```
   - Check import success rate
   - Review error log for failed imports
   - Manually add any missing contacts

2. **Items Verification:**
   ```
   Items → All Items
   ```
   - Verify count matches your export
   - Spot-check HSN codes
   - Ensure tax rates are assigned

3. **Invoices Verification:**
   ```
   Reports → Transaction Detail Reports
   ```
   - Compare total sales/purchases with your old system
   - Verify GST calculations
   - Check that all parties have associated invoices

4. **GST Reports:**
   ```
   Reports → GST Reports → GSTR-1 / GSTR-3B
   ```
   - Generate trial GST reports
   - Compare with your previous GST returns
   - Ensure data integrity

### Step 10: Clean Up and Configuration

1. **Delete Test Data** (if you imported test files first)
2. **Set Up Automation:**
   - Invoice numbering sequences
   - Email templates for invoices
   - Payment reminders
   - Recurring invoices (if applicable)

3. **Configure Preferences:**
   - Settings → Preferences → Invoices
   - Set default terms and conditions
   - Configure invoice template
   - Set up payment gateways

4. **User Access:**
   - Settings → Users
   - Add team members and set permissions

## Troubleshooting Common Issues

### Issue: "Customer not found" error during invoice import
**Solution:** 
- Ensure contacts were imported first
- Check that customer names match exactly (case-sensitive)
- Import contacts again if needed

### Issue: Duplicate GSTIN errors
**Solution:**
- Zoho Books requires unique GSTINs
- If multiple parties share a GSTIN (shouldn't happen legally), consolidate them
- Remove duplicate GSTINs before re-importing

### Issue: Invalid GSTIN format
**Solution:**
- The export script validates GSTIN format
- Check source database for malformed GSTINs
- Fix in source database and re-export

### Issue: Tax calculation mismatches
**Solution:**
- Verify tax rates are set up correctly in Zoho
- Check if inter-state vs intra-state logic is correct (IGST vs CGST+SGST)
- Update item tax preferences in Zoho

### Issue: Invoice numbers already exist
**Solution:**
- Zoho requires unique invoice numbers
- If re-importing, delete previous imports first
- Or use different invoice number series

## Data Mapping Reference

### Contacts Export Mapping

| Database Field | Zoho Books Field | Notes |
|----------------|------------------|-------|
| `parties.name` | Contact Name | Primary identifier |
| `parties.gstin` | GSTIN | Must be valid format |
| `parties.party_type` | Contact Type | customer/vendor/both |
| `parties.city` | Billing City | Also mapped to shipping |
| `parties.state` | Billing State | Used for GST calculation |
| `parties.id` | Custom Field 1 | Original ID for reference |

### Items Export Mapping

| Database Field | Zoho Books Field | Notes |
|----------------|------------------|-------|
| `items.canonical_name` | Item Name | Product name |
| `items.id` | SKU | Format: ITEM-{id} |
| `items.hsn` | HSN/SAC | For GST classification |
| `items.id` | Custom Field 1 | Original ID |
| `items.is_prepackaged_labelled` | Custom Field 2 | Compliance flag |

### Invoice Export Mapping

| Database Field | Zoho Books Field | Notes |
|----------------|------------------|-------|
| `invoices.invoice_no` | Invoice Number | Must be unique |
| `invoices.invoice_date` | Invoice Date | YYYY-MM-DD format |
| `parties.name` | Customer Name | Must match imported contact |
| `invoice_items.quantity` | Quantity | Line item quantity |
| `invoice_items.rate` | Rate | Unit price |
| `invoice_items.*_rate` | Tax | Calculated from CGST+SGST+IGST |

## Post-Migration Best Practices

1. **Run parallel systems** for 1-2 months to ensure accuracy
2. **Backup Zoho data** regularly (Settings → Backup)
3. **Train team members** on Zoho Books interface
4. **Set up integrations** if needed (payment gateways, banking)
5. **Review reports** monthly and compare with old system
6. **Update workflows** for new invoicing process

## Custom Field Reference

The export utility stores original database IDs in custom fields for future reference:

- **Contacts Custom Field 1:** Original `parties.id`
- **Contacts Custom Field 2:** Original `party_type` (customer/supplier/both)
- **Items Custom Field 1:** Original `items.id`
- **Items Custom Field 2:** Prepackaged/Labelled flag

You can use these fields to maintain a mapping between your old system and Zoho Books if needed.

## Notes

- The export script only exports **active items** (`is_active = 1`)
- Only **finalized invoices** (`status = 'final'`) are exported
- Draft and cancelled invoices are excluded
- Multi-line invoices are exported with one row per line item
- Zoho Books will group them by invoice number during import
- Tax calculations use the sum of CGST, SGST, and IGST from your database
- You may need to reconfigure tax rates in Zoho if they differ
